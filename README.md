# Temporal Memory Graph Hindsight Agent

This example demonstrates an AI agent that builds a temporal memory graph of its actions and perceived outcomes. It then applies a 'hindsight' mechanism to re-evaluate these past actions based on a final, global outcome. This allows the agent to learn from its experiences by understanding the long-term strategic value of its decisions, rather than just immediate rewards.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
